# EADROS Glossary

* **DevRel OS:** Developer Relations Operating System. An automated platform for mining engineering activities and managing community growth.
* **Story Mining:** The process of scanning git commits, PRs, releases, and ADRs to identify technical narratives.
* **Category Positioning (Wave 0):** Defining a project's unique value proposition relative to existing developer tools *before* any distribution campaign runs. Enforced as a gate by `eadros launch`, not offered as advice. Referred to as *Onda 0* in the original Italian drafts; **Wave 0** is the canonical English term used throughout the specification.
* **Angle Agent:** Specialized LLM agent responsible for framing a raw engineering event into a compelling technical perspective (e.g. bug post-mortem, performance optimization).
* **Human-in-the-Loop (HITL):** Governance model where human maintainers review and approve content before publishing.
* **Awesome List Backlink:** Permanent inclusion of a repository in curated "Awesome" lists on GitHub.
