# ADR-0001: Project Purpose and Core Positioning

* **Status:** Approved
* **Date:** 2026-07-28
* **Context:** Open source maintainers lack time for Developer Relations, leading to high abandonment rates for quality codebases. Traditional social media tools produce shallow, promotional content that developer communities reject.
* **Decision:** We will build EADROS as an Open Source Developer Relations Operating System (DevRel OS). It will observe engineering activity directly (commits, PRs, ADRs, releases) and orchestrate AI agents to generate authentic, high-value technical content.
* **Consequences:**
  * Positive: High developer trust, automated storytelling from real engineering work.
  * Negative: Requires parsing complex git structures and maintaining multi-provider LLM integrations.
