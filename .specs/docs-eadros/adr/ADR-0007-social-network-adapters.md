# ADR-0007: Channel-Native Social Adapters

* **Status:** Approved — **extended by [ADR-0011](ADR-0011-channel-capability-tiers.md)**, which governs *whether* an adapter may publish at all. This ADR governs only formatting.
* **Date:** 2026-07-28
* **Context:** Posting identical text to LinkedIn, Dev.to, X/Twitter, and Reddit results in low engagement and community backlash.
* **Decision:** EADROS will use Channel-Native Adapters. Each adapter enforces platform rules (e.g. character limits, Markdown vs plain text, code block formatting, tag insertion).
* **Consequences:** Maximizes organic resonance on each developer network.
